# Dependency security — PARTIAL

On 2026-10-31 Hostinger reported two moderate instances of CVE-2026-118764 in deployed `minimatch` versions 10.2.6 and 3.1.5. The candidate lockfile also includes both versions. A fresh `pnpm@11.24.0 audit --audit-level moderate` returned exit 1 with one moderate advisory and 70 dependency paths; the result is not a clean audit. Paths include ESLint/configuration tooling. This does not prove remotely exploitable application behavior; the advisory requires an attacker-controlled glob and optimization level at least 2.

The registry/GitHub advisory currently describes affected versions as `<11.0.1`, while the [maintainer's advisory](https://github.com/isaacs/minimatch/security/advisories/GHSA-g3hv-75wg-m249) specifically identifies 10.2.6 and 11.0.1 as patched. Treat that discrepancy conservatively. Forcing all older major versions to v11 is a breaking cross-major override, not a verified compatible patch, and may break callers expecting older exports. No dependency changes or hosted patch were made. Review upstream compatible fixes and dependency paths in isolation, retest the complete tree, and repeat the audit before release. The previously recorded clean audit predates this new finding.
