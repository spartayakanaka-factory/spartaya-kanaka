# Media persistence — BLOCKED

The existing implementation uses distinct S3-compatible originals and display buckets. Payment evidence is written to the originals bucket and is read through an authenticated authorization-checked API, with short-lived viewer-bound signatures and content verification. Public product display images use the separate display bucket. Bucket separation in code is not proof that a provider's originals bucket or credentials are private; bucket ACL/policy and direct object reads must be tested independently.

No `MEDIA_S3_*`, `MEDIA_ACCESS_KEY_ID`, `MEDIA_SECRET_ACCESS_KEY` or `MEDIA_PUBLIC_BASE_URL` names were visible in the staging panel. Filesystem durability across Hostinger rebuilds and backup coverage are unverified. `LEGACY_ASSET_ROOT` is configured by name; its value, contents, permissions and durability were not inspected here. Do not move, delete or overwrite the original 1,753 images.

Select a supported S3-compatible service only after confirming cost and authorization. Configure HTTPS endpoint, separate private originals and display buckets, least-privilege server credentials, a public display base and optional region/path-style settings through server-side secrets. Never serve payment evidence from public display storage. Before use, test synthetic upload, direct anonymous denial of originals, authorized API reads, duplicate names, missing objects, process restart, deployment replacement, backup and recovery. Keep upload/financial features disabled until persistent storage and privacy are proven on the actual service. Prior disposable object-storage tests are local evidence only.

In the remediation workstream a separate loopback-only disposable S3 service was started on a fresh port. Synthetic product and evidence objects were uploaded, anonymous private reads and listing were rejected, the store was restarted, and the bytes of both objects matched. A private object was read into memory, deleted, restored and verified. The isolated service was stopped afterward. This verifies a local service restart and object-level restore only; it is not an independent durable backup, deployment simulation, a hosted provider policy, or proof that any production storage is private.
