Concrete engineering blocker: checking a marker on one pooled database connection is not proof that later Prisma reads or writes use that same connection. A complete implementation must bind attestation to the actual execution/transaction connection and apply it to APIs, server actions, Better Auth callbacks, workers and Phase 2 administrative mutations. It must additionally establish server-controlled synthetic principals and independently isolate storage, financial providers and notifications. Enabling a staging flag before those controls exist would violate the requested fail-closed behavior.
