# Remaining live merchant decisions

The accepted Phase 3/M0 register is preserved. Phase 3.5 authorization permits the local synthetic implementation and tests, **not** activation of unresolved real financial policies. These gates apply to later merchant/hosted activation; a passing local fixture does not approve its amounts or terms.
